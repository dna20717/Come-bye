# Come Bye 🐑🐕

Ein kleines Pixel-Spiel für Handy und Browser rund um Border Collies.

**Spielen:** https://dna20717.github.io/Come-bye/

## Spielmodi
- **Hüten:** Treib zehn Schafe ins Gatter. Tippen oder Ziehen lenkt deinen Collie, dazu kommen echte Hütekommandos wie *Come bye*, *Away to me*, *Walk up* und *Lie down*. Wer hetzt, stresst die Herde.
- **Agility:** Zufällige Parcours mit Hürde, Reifen, Tunnel, Slalom, A-Wand, Steg, Wippe und Tisch. Mit *Hopp!*, *Langsam* und *Lie down* vermeidest du Fehler, jeder kostet 5 Sekunden.

## Die Collies
| Hund | Typ | Besonderheit |
|------|-----|--------------|
| Nala | grau, schnell, klug | bremst nahe der Herde von selbst, Slalom sitzt immer |
| Juni | schwarz, etwas größer, brav | ruhige Herde, trifft die Kontaktzonen |
| Fly | schwarz-braun, der Größte, sehr schnell, frech | macht gern sein eigenes Ding |

Dazu: vier Jahreszeiten, Zufallskarten, Collies dürfen in den Teich, und eine Schäferin, die ihre Kommandos in Fantasie-Simlish ruft. Alle Sounds entstehen live per Web Audio.

## Technik
Eine einzige `index.html` ohne Abhängigkeiten (nur die Schrift „Pixelify Sans“ von Google Fonts).
